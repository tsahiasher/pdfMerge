========================================================================
                      .NET BUILD & PUBLISH COMMANDS
========================================================================

1. BUILD FOR DEBUG:
-------------------
dotnet build


2. BUILD FOR RELEASE:
---------------------
dotnet build -c Release


3. BUILD FOR PUBLISH (STANDALONE SINGLE-FILE EXE):
---------------------------------------------------
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:IncludeAllContentForSelfExtract=true -p:EnableCompressionInSingleFile=true -o ./publish

(The standalone executable will be generated at: ./publish/pdfMerge.exe)


4. BUILD INSTALLER SETUP EXE (INNO SETUP 7):
----------------------------------------------
"C:\Program Files\Inno Setup 7\ISCC.exe" "pdfMerge_Installer.iss"

(The installer setup file will be generated at: ./Output/PDFMerge_Setup_v1.0.0.exe)
